# Fariha Mart - Retail Sales Analysis (SQL & Power BI)

## 📌 Project Overview
This project focuses on analyzing the retail sales data of Fariha Mart. The main goal of this project is to extract raw data using MS SQL Server, clean and transform it, and then create interactive dashboards in Power BI to uncover valuable business insights. 

The dashboard provides a comprehensive view of sales performance, helping stakeholders make data-driven decisions regarding inventory, marketing, and customer targeting.

## 🛠️ Tools & Technologies Used
*   **Database Management:** MS SQL Server (Data extraction, cleaning, and querying)
*   **Data Visualization:** Power BI Desktop
*   **Data Modeling:** Star Schema (Fact and Dimension tables)
*   **Calculations:** DAX (Data Analysis Expressions) for creating custom measures and KPIs.

## 📊 Key Features & Insights
The Power BI dashboard includes the following key performance indicators (KPIs) and visualizations:
*   **Executive Summary:** Total Revenue, Total Profit, Total Orders, and Profit Margin.
*   **Sales Trends:** Monthly and Yearly sales analysis to identify peak business seasons.
*   **Product Performance:** Identification of Top 5 best-selling products and low-performing inventory.
*   **Customer Demographics:** Analysis of sales based on customer location, age group, and purchasing behavior.
*   **Interactive Filters:** Slicers for Date, Region, and Product Category to allow dynamic data exploration.
